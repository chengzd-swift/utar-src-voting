Student Roster

The Department of Student Affairs export. Registrations are matched against it and verified automatically, so approval scales with the number of exceptions rather than the number of students.

📥 Import Roster (.xlsx)

Upload the DSA export as an Excel spreadsheet. First row is the header. Required: student_id, full_name, email, faculty, campus. Optional Reg 4 and Reg 14 columns: study_level, is_international, delivery_mode, sat_first_exam, trimesters_left, on_leave, academic_probation, criminal_offence, disciplinary_guilty, disciplinary_open, fees_in_arrears, president_waiver, deemed_unfit. Re-importing updates students who are already on the roster.

🕘 Import history

Every roster row remembers which import last wrote it, so this is what each upload actually left behind. Re-importing a student moves them to the newer import.

AI Assistant

The election assistant students see on every page. Only the Election Committee can configure it. The API key is stored encrypted and is never sent to a student's browser — questions go to this server, and this server talks to the provider.

🔌 Provider
Leave blank to keep the key already saved.
🎛️ Model behaviour

Lower temperature keeps answers close to the regulations. This assistant quotes rules rather than brainstorming, so 0.2–0.4 suits it. Top-k applies to Google models only.

How much it varies its wording. At 0 the same question gets almost the same answer every time; at 1.5 it rephrases freely and starts paraphrasing rules loosely. Keep it 0.2–0.4 — this assistant quotes regulations.
How wide a pool of words it picks from. 0.9 keeps the most likely 90% and ignores the odd tail. Leave at 0.9 — adjust temperature or this, not both.
A hard cap on that pool: at most 40 candidate words. Google models only — OpenAI and OpenRouter ignore it.
Where the answer gets cut off. Roughly ¾ of a word per token, so 700 ≈ 500 words. 600–800 fits a full Regulation 4 answer without overflowing the chat panel.
📝 System prompt

What the assistant knows and how it behaves — the regulations it answers from, its tone, and the instruction to refer students to the DSA rather than guess. Edit with care: this is the whole of its knowledge.
